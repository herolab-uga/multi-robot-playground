Position

Additive Gaussian error on x and y plus a per-run random bias.

Distance

Additive Gaussian range error; measurements disappear beyond sensing range.

Bearing

Gaussian angular error in degrees, converted internally to radians.

RF / RSSI

Log-distance path-loss model with Gaussian shadowing: RSSI = P₀ − 10n log₁₀(d/d₀) + noise.

Radar

Range + bearing measurement with configurable noise and finite detection range.

Dropout

Independent Bernoulli packet/measurement loss per observation, useful for robustness exercises.

Set to 1 for every control step, 2 for half-rate sensing, etc. Measurements are held between sensor updates.

Per-robot sensor overrides

Keys are zero-based robot IDs. Override on, noise, bias, range, or drop for any sensor.

Control Barrier Function safety layer

The safety layer runs after the nominal controller. It minimally modifies each command to satisfy configured safety inequalities where possible.

For single-integrator collision safety, the filter uses \(h_{ij}=\|p_i-p_j\|^2-d_{safe}^2\) and enforces \(\dot h_{ij}+\alpha h_{ij}\ge 0\). The implementation uses repeated half-space projections as a lightweight browser alternative to a full QP solver.

Execution order

1. Sensors / observations 2. Nominal controller 3. Built-in CBF safety filter 4. Optional Python safety_filter() 5. Speed saturation 6. Robot dynamics

This separation lets students compare task control and safety enforcement without embedding collision logic inside every controller.
